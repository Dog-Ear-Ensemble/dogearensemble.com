# dogearensemble.com

The website for Dog Ear Ensemble, served by GitHub Pages (Jekyll).

## Layout

| Path | What it holds |
|------|---------------|
| `_config.yml` | Site name, description, nav menu, links. |
| `_layouts/default.liquid` | The page shell. |
| `_includes/*.liquid` | Head, header, footer, and page sections. |
| `*.html` | One file per page, with front matter. |
| `assets/` | `style.css` and the icons (made from the app icon). |

## Rules

- No trackers, analytics, third-party fonts, or third-party scripts.
- Use the full name, Dog Ear Ensemble, never a bare part of it.

## Local preview

```bash
bundle install
```

```bash
bundle exec jekyll serve
```
